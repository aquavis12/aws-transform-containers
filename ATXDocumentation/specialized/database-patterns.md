# Database Patterns

## Schema Design

### Table: `users`
- **Engine**: InnoDB (transactional, row-level locking)
- **Character Set**: utf8mb4 (full Unicode support)
- **Collation**: utf8mb4_unicode_ci (case-insensitive comparisons)

### Indexes
| Index | Column(s) | Type | Purpose |
|-------|-----------|------|---------|
| PRIMARY | id | Clustered | Primary key lookup |
| idx_username | username | Unique B-tree | Username lookups and uniqueness |
| idx_email | email | Unique B-tree | Email lookups and uniqueness |
| idx_created_at | created_at | B-tree | Time-based queries |

### Column Design
- Auto-increment BIGINT primary key (suitable for high-volume inserts)
- VARCHAR with appropriate limits (100 for names, 500 for address, 20 for phone)
- TIMESTAMP with DEFAULT CURRENT_TIMESTAMP for audit trails

## Query Patterns

### Generated by Spring Data JPA (Derived Queries)
```sql
-- findByUsername
SELECT * FROM users WHERE username = ?

-- findByEmail
SELECT * FROM users WHERE email = ?

-- findByFirstNameIgnoreCase
SELECT * FROM users WHERE LOWER(first_name) = LOWER(?)

-- findByLastNameIgnoreCase
SELECT * FROM users WHERE LOWER(last_name) = LOWER(?)

-- findByPhoneNumber
SELECT * FROM users WHERE phone_number = ?

-- existsById
SELECT COUNT(*) FROM users WHERE id = ?
```

### Custom JPQL Query
```sql
-- searchByName (translated to SQL)
SELECT * FROM users 
WHERE LOWER(first_name) LIKE LOWER(CONCAT('%', ?, '%'))
   OR LOWER(last_name) LIKE LOWER(CONCAT('%', ?, '%'))
```

## Hibernate Configuration

| Setting | Value | Purpose |
|---------|-------|---------|
| ddl-auto | update | Auto-schema evolution (dev only) |
| batch_size | 20 | Batch INSERT/UPDATE operations |
| order_inserts | true | Optimize batch inserts |
| order_updates | true | Optimize batch updates |
| dialect | MySQL8Dialect | MySQL 8.0 SQL generation |

## Connection Pooling

- **Pool**: HikariCP (Spring Boot default)
- **Configuration**: Default settings (min=10, max=10 for HikariCP defaults)
- **JBoss config**: Custom pool (min=10, max=20) defined in standalone.xml
